## User story

```
As a manager, I want to log in to the application and walk through the entire "All Employees" directory page by page so that I can confirm — name by name, not by count — that every employee listed in my exported CSV is actually present in the live directory, with nobody missing and no extras added.

To do this I open the application at http://localhost:5173/ in my browser, where I am greeted by the login screen. I enter my Manager ID 499 in the username field and the password Mngr@101Pass! and click Login, which lands me on http://localhost:5173/dashboard/499. From the dashboard I click "View All Employees" and navigate to http://localhost:5173/all-employees/499. Once there I set the filter dropdown to "All Employees" so I am working against the full directory rather than a single department, and I clear the search box so no rows are accidentally hidden. With my CSV (employees_all_2026-05-18.csv) open beside the browser, I read the first ten names in the table and tick each one off in the CSV, using the Emp ID to disambiguate when two people share a name. I then click the right-arrow ">" button in the pagination footer to advance to the next ten rows and repeat the same name-by-name check, watching the "Page X of Y" indicator to know how far along I am. I keep going until I reach the last page (which may contain fewer than ten rows), and if I lose my place I use the left-arrow "<" button to step back to an earlier page and recheck. At the end of the walk every CSV row should be ticked off, and no employee shown on screen should be absent from the CSV.
```
